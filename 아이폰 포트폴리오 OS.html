iOS 포트폴리오 웹 사이트

GitHub Pages 전용 대화형 템플릿

아이폰 UI 디자인을 내 포트폴리오로 활용할 수 있는 웹 앱입니다. 실제로 구동되는 **잠금화면, 다이내믹 아일랜드, 프로젝트 갤러리, 방명록(LocalStorage 저장)** 등을 체험해보세요!

깃허브(GitHub Pages) 무료 배포 방법

  1. GitHub에 로그인 후 새 Repository 생성
    저장소 이름: 내아이디.github.io
  2. 이 페이지 코드 전체를 복사하여 index.html 파일로 저장
  3. 생성한 Repository의 main 브랜치에 업로드
  4. 저장소 **Settings > Pages** 이동
  5. Branch를 **main / (root)** 로 설정 후 **Save** 클릭
  6. 약 1~2분 뒤 https://내아이디.github.io 주소로 나만의 아이폰 사이트 완성!
